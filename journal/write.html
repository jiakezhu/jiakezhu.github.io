如何发布到网站

1. 导出文件，放入仓库的 content/posts/ 目录。

2. 将文件头部的 draft: true 改成 draft: false。

3. 在仓库运行 npm ci && npm run build，然后提交并推送 Markdown 和生成的页面。GitHub Pages 将发布更新。

未来日期的文章暂不生成；到日期后重新运行构建即可发布。草稿文件也不要提交私人信息，因为这个 GitHub 仓库是公开的。
